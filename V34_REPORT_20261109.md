## Exact v34 architecture and state

Unchanged 168-input preprocessing → Linear(168,64) → ReLU → eight residual blocks → Linear(64,2).

Each block, with dilation d in **1,2,4,8,16,32,64,128**, computes:

`x_next = ReLU(x + Pointwise64x64(ReLU(DepthwiseConv64(kernel=3, dilation=d)(history || x)))))`

Both convolutions have biases. Depthwise convolution acts only along time; pointwise mixing operates on learned channels. There is no convolution along book-feature indices, dropout, batch/layer normalization or sequence-dependent normalization. Only the existing fixed training-set preprocessing statistics are used. Receptive field: **511 rows**. Parameters: **46,274**, versus GRU control **213,762**.

Each block caches its own **input** history of shape `(batch,64,2*d)`, oldest first. Chunked forward prepends this history and applies an unpadded temporal convolution. Cached-row inference uses exactly the three taps at t−2d, t−d and t, then shifts that block's cache. Initial history is zero; projection/convolutions still process every warm-up row. State is carried across 1,000-row chunks, detached only after each optimizer update, and reset only between independent sequences. Row and batched APIs share the same state layout.

Single-sequence cached-row history: **32,640 float32 values = 130,560 bytes = 127.5 KiB**. Raw-input streaming also carries 44 previous prices (176 bytes). The IOBinding adapter double-buffers history (**255 KiB** total history buffers). Training cache tensors are views into concatenated chunk storage; training allocation is measured below, not inferred from the logical row-state size.

The TCN's CPU initialization RNG is forked (seed 34,000,000 + init seed). Adding it does not advance the control RNG. The unchanged `train_multi.py` supplies one shared data stream: 10,307 train sequences, 300 holdout, 1,873 valid; identical order, 64-sequence statistics, mask-weighted loss and optimizer settings for both models. Full recipe: seeds 0, batch16/chunk1000, five epochs = 64,500 updates/model, AdamW lr .001, wd .05, cosine schedule, clipping norm1, alpha .5 and existing `train_maskp.npy`. The shared CLI's hidden128/layers2 describe the GRU; TCN width64/depth8 are fixed in its class.
